# 传送带产品计数与堵塞蓝牙报警系统
## 📖项目简介
基于STM32 HAL库开发的工业简易监测系统，实现产品计数、传送带堵塞检测、声光报警、蓝牙双向通信。可完成实时计数采集、堵塞故障告警，支持手机蓝牙读取数据、清零操作。

## 🛠技术栈
- 主控：STM32
- 开发框架：STM32CubeMX + HAL库
- 外设：光敏传感器、OLED、数码管、蓝牙模块、声光报警模块
- 通信：GPIO、ADC、I2C、USART、TIM定时器

## ✨核心功能
1. 产品计数：光敏传感器采集信号，定时器软件消抖，过滤电平毛刺，降低漏计、重复计数
2. 堵塞检测：传感器持续遮挡超时逻辑判断，识别传送带堵塞，触发声光报警；故障解除自动恢复
3. 本地显示：OLED、数码管实时展示计数数值与设备状态
4. 蓝牙双向通信：上报计数、告警状态；手机端可查询计数、执行清零、读取设备状态
